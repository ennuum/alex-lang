Modèles :
  console   Application console — Programme en ligne de commande avec module, tests unitaires et intégration continue.
  gui       Application graphique — Application de bureau ui.view (Windows, X11, ou terminal) : sources en couches (modèles, services, vues), données persistantes, ressources, tests, scripts de construction.
  cli       Outil en ligne de commande — Commandes et options (argparse), aide, page de manuel et complétion shell générées.
  lib       Bibliothèque — Paquet réutilisable (alexc pkg) : module documenté, tests, exemple, publication.
  server    Serveur web — Serveur HTTP/1.1 (network.http) avec routes JSON ; la logique des routes est testée sans réseau.
  kernel    Noyau de système d'exploitation — Noyau démarrable sans OS (Multiboot, x86-64) : écran VGA, port série, horloge ; démarré dans QEMU.
  driver    Pilote de périphérique — Pilote d'un périphérique à ports d'E/S, testé dans la machine simulée (hw) puis utilisable dans un noyau.
